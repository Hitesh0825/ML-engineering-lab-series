# Exercise 4: Random Forest — Classification

## Objective
Use an ensemble of decision trees to classify bank marketing outcomes.

## Dataset
`data/raw/bank_marketing.csv`

## Workflow
- Train a Random Forest with bootstrap sampling.
- Evaluate OOB score, F1, recall, and ROC-AUC.
- Analyze feature importance.
- Save predictions and importance values.

## Acceptance Criteria
- OOB score >= 0.88
- F1 score >= 0.65

`notebooks/04_random_forest.ipynb`

- `outputs/exercise4_feature_importance.csv`
